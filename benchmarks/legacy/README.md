# Legacy Intel benchmark evidence

These are the unique raw text and derived CSV files retained from the repository's
original Gaussian-blur experiment on an Intel Core i7-12700 and Intel UHD Graphics
770. `image-level/` assigned complete images; `split-image/` divided each image by
rows.

Duplicate ZIP archives and a second nested copy of the split-image logs were
removed. The files are historical evidence only: they do not benchmark FlowGuard's
optical-flow pipeline and must not be compared directly with current results. The
old README's heterogeneous speedup headline was not sufficiently supported
as a portable claim and is intentionally not repeated.
